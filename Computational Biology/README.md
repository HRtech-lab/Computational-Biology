# Computational Biology

| Course | Worked lectures | Starting points |
|---|---:|---|
| [Computational Genomics](Computational%20Genomics/README.md) | 20 | Pairwise alignment, sequence indexing, mapping, assembly and population summaries |
| [Computational Proteomics](Computational%20Proteomics/README.md) | 15 | Digestion, fragment masses, spectral analysis, protein inference, quantification and structural alignment |

Each numbered folder contains Python, an executed notebook, a worked figure, numerical checks and references. The examples use invented sequences, peptide standards and synthetic observations, plus the public 1UBQ ubiquitin structure in the Foldseek lecture. [Environment and reuse](../README.md)
